# Security Policy

## Supported versions

Only image tags listed as supported in the latest GitHub release receive security rebuilds. Deploy by digest to avoid unintended tag movement.

## Reporting

Report suspected vulnerabilities through GitHub private vulnerability reporting. Do not disclose exploitable details in a public issue.

## Update response

Samba and AlmaLinux advisories are reviewed against supported image lines. Fixes are built, integration-tested, scanned, signed, and published through the normal release workflow. If no upstream fix exists, affected tags may be withdrawn or documented as temporarily unsupported.
